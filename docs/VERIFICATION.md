# 实测验证记录

这份文件记录各版本交付前真正跑过的验证，用来回答「这东西到底验到什么程度了」。
README 里只放结论，细节都在这里。

复现方式：`selftest.bat`（无界面自检）、`demo.bat`（内置 4 台模拟打印机）、
`test.bat`（离线回归套件）。需要真机的项目无法复现，所以逐条写清了设备与固件环境。

## 真机环境

同一局域网内 13 台拓竹打印机：X1C、X2D、P1S×5、A1×2、A1 mini、P1P，
另有 A2L、H2S 用于固件差异结论（见 [`FIELD_NOTES.md`](FIELD_NOTES.md)）。

## 还没验证过的

- **安卓设备上的完整回归**：构建机没有安卓设备，也跑不动模拟器。已确认的是
  APK 能构建、模块都在包里、页面与接口契约正确（用子进程与 HTTP 层断言）。
  1.0.6 起安卓版的 RTSPS 画面通路也没有在真机上绘制过（取流、传输、可解码都已验证）。
- **Moonraker 系的真机**：Voron、Snapmaker U1 都没接上跑过，控制指令只在假服务器上验证。
- **Linux GUI 版的实机桌面**：只用离屏与容器验证过，没有在真实桌面环境里长时间挂着跑。
